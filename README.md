# 预约后台管理系统

PC 端预约看板：管理员登录后，按「星期 × 时段」查看和安排预约。前端 Vue 3，接口目前用本地 Mock 模拟，没有真实数据库。目前只有管理员账号，管理员负责登记预约，用户自己无法预约，后续会加入用户账号，用户可自行登录预约，并加入权限管理。还会加入设置功能，用来设置表格大小，和具体可预约时间安排。

## 功能

- **登录：** 默认初始账号：13800000000 密码：123456
- **看板：** 默认周一至周六、每天 9:00–18:00、一格 1 小时。表头带本周日期。可根据需求更改
- **新建预约：** 点空闲格，选择服务并填写客户姓名（备注可选）。
- **占位规则：** 已被占用的时段不能再约；会超出当天结束时间（例如 17:00 约 2 小时服务）会被拒绝。占两格及以上的预约在表格里合并成一格。
- **取消：** 点已占格打开详情，点取消即释放格子，无需二次确认。

## 运行

需要 Node 18 或以上。

```bash
npm install
npm run dev
```
