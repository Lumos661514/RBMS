# 预约后台管理系统

面向服务类门店的预约后台：前端 Vue 3 + Vite，后端 Node.js + Express，数据存 MySQL。开发时浏览器访问前端，`/api` 由 Vite 转到 Express，看起来仍是同域。

- 在线演示：[http://120.27.130.34](http://120.27.130.34)
- 源码：[https://github.com/Lumos661514/RBMS](https://github.com/Lumos661514/RBMS)

## 账号

- 可注册普通用户，角色固定为用户，成功后自动进入看板。
- 管理员账号属于系统自带，无法创建且只有一个

## 功能

- **预约看板：** 从今日起按设置画出时段表。管理员代约普通用户（不能约自己），可查看并取消格内全部预约；普通用户只能查看/取消自己的单，开约前 30 分钟内不可取消。
- **员工与容量：** 预约须选空闲员工；同一员工同时段不可重复约；同一用户同时段只能约一名员工；全员约满该格才关闭。
- **用户管理：** 普通用户看自己的资料、预约记录（含本次消费与总计消费）、改自己的密码。管理员可搜索普通用户、改其密码、删除账号（不删除已有预约记录）。
- **项目介绍 / 项目管理：** 介绍页展示价格、时长与简介。管理员可新增、修改、删除项目，变更同步到介绍页和预约下拉；已产生的预约仍保留当时的项目名。
- **员工管理（仅管理员）：** 添加/编辑员工并勾选可做项目。
- **系统设置（仅管理员）：** 营业起止整点、时间格（最低 30 分钟、步进 30）、看板列数（最少 7）。
- **时段规则：** 已过开始时刻不可再约；到点后看板清空占用，记录保留为「已结束」。



## 本地运行

需要 Node 18+ 和 MySQL 8。

```bash
cp .env.example .env
# 按本机 MySQL 改 DB_USER / DB_PASSWORD；库名默认 booking，没有会自动建
# 也可用 Docker：docker compose up -d

npm install
npm run dev
```

首次启动会建表；`users` 为空时只写入内置管理员，项目、员工和预约需在后台添加。之后读写都在 MySQL。
