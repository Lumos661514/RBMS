# 预约后台管理系统

PC 端预约系统：该系统设计的目的是提供更便捷的预约服务，

## 账号

- 内置管理员 `13800000000` / `123456`：不可改、不出现在用户管理里。
- 登录页可注册普通用户，角色固定为用户，成功后自动登录进看板。忘记密码入口暂未开放。

## 功能

- **预约看板（管理员和用户都能进）：** 点空闲格预约，预约人绑当前登录账号。用户只能取消自己的预约，管理员可取消任意预约。
- **用户管理：** 普通用户只能看自己的资料、预约记录、改自己的密码。管理员只看到普通用户，可改其密码、删除账号（不删除已有预约记录）。
- **系统设置（仅管理员）：** 修改营业开始/结束整点和星期，看板按新设置画表。

## 运行

需要 Node 18 或以上。

```bash
npm install
npm run dev
```
