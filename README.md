# 预约后台管理系统

PC 端预约系统：该系统设计的目的是提供更便捷的预约服务，

## 账号

- 内置管理员 `13800000000` / `123456`：不可改、不出现在用户管理里。
- 登录页可注册普通用户，角色固定为用户，成功后自动登录进看板。忘记密码入口暂未开放。

## 功能

- **预约看板（管理员和用户都能进）：** 点空闲格预约。管理员只能代约普通用户（不可约自己），可查看格内全部预约并取消；普通用户只能查看/取消自己的预约。用户开约前 30 分钟内不可取消（管理员不限）。
- **用户管理：** 普通用户只能看自己的资料、预约记录、改自己的密码。管理员只看到普通用户，可改其密码、删除账号（不删除已有预约记录）。
- **系统设置（仅管理员）：** 修改营业开始/结束整点、时间段（每格分钟数，最低 30、步进 30）和看板列数，看板按新设置画表。
- **预约看板：** 第一列从今日起，表头统一为「星期 + 月/日」；列数由设置控制。预约记录展示日期带年份（如 2026/9/18）。
- **员工管理（仅管理员）：** 添加员工并配置可做项目；预约须选空闲员工，同一员工同时段不可重复约，全员约满该格才关闭。
- **时段规则：** 已过开始时刻的格子不可预约；预约一到开始整点即从看板清空占用，记录保留为「已结束」。
- **项目介绍：** 展示全部服务的价格、时长与简介。
- **项目管理（仅管理员）：** 新增服务，或修改名称、价格、时长与简介；变更会同步到项目介绍和预约下拉。

## 运行

需要 Node 18 或以上。

```bash
npm install
npm run dev
```
